# PHASE 7 — Backend Lambda Services (Complete Detailed Guide)

# Main Goal

Build production-grade backend microservices using:

* AWS Lambda
* Amazon API Gateway
* Amazon DynamoDB
* Amazon SQS
* Amazon SNS
* AWS Step Functions

This phase is where your actual business logic is built.

---

# PHASE 7 Architecture

```text id="jlwm501"
Frontend
    ↓
API Gateway
    ↓
Lambda Services
    ↓
DynamoDB / SQS / SNS / S3
```

---

# Backend Architecture Pattern

You are NOT building:

* one huge Lambda

You are building:

* multiple microservice Lambdas

Enterprise pattern.

# What Each Layer Does

| Layer       | Responsibility        |
| ----------- | --------------------- |
| handler     | HTTP request handling |
| service     | business logic        |
| repository  | DB access             |
| utils       | helpers               |
| validations | request validation    |

# APIs You Should Build

# AUTH SERVICE

| API               | Purpose  |
| ----------------- | -------- |
| POST /auth/signup | Register |
| POST /auth/login  | Login    |
| POST /auth/logout | Logout   |

---

# PRODUCT SERVICE

| API                   | Purpose        |
| --------------------- | -------------- |
| GET /products         | List products  |
| GET /products/{id}    | Product detail |
| POST /products        | Create product |
| PUT /products/{id}    | Update product |
| DELETE /products/{id} | Delete product |

---

# CART SERVICE

| API                     | Purpose       |
| ----------------------- | ------------- |
| GET /cart               | User cart     |
| POST /cart/items        | Add cart item |
| DELETE /cart/items/{id} | Remove item   |

---

# ORDER SERVICE

| API              | Purpose      |
| ---------------- | ------------ |
| POST /orders     | Place order  |
| GET /orders/{id} | Order detail |
| GET /orders/user | User orders  |

---

# UPLOAD SERVICE

| API                         | Purpose             |
| --------------------------- | ------------------- |
| POST /uploads/presigned-url | Generate upload URL |

# PHASE 8 — Backend CI/CD Pipeline (Complete Detailed Guide)

# Main Goal

Automate:

* Lambda testing
* Lambda packaging
* deployment
* environment promotion

using:

* GitHub Actions
* Terraform
* AWS Lambda deployment

---

# Backend CI/CD Architecture

```text id="’wini512"
GitHub Push
    ↓
backend.yml
    ↓
Detect Changed Services
    ↓
Install Dependencies
    ↓
Lint
    ↓
Run Tests
    ↓
Security Scan
    ↓
Package Lambda
    ↓
Terraform Apply
    ↓
Deploy Lambda
```

---

# Important Enterprise Concept

You should have:

* ONE backend.yml

NOT:

* one YAML per Lambda

---

# How Single Pipeline Works

Pipeline detects:

* which service changed

Then deploys only that service.

---

# Example

If only:

```text id="’wini513"
backend/order-service/*
```

changed,

pipeline deploys only:

* order-service

---

# Backend Pipeline Responsibilities

| Stage         | Purpose              |
| ------------- | -------------------- |
| Install       | install dependencies |
| Lint          | code quality         |
| Test          | validate logic       |
| Security Scan | vulnerability checks |
| Package       | create Lambda ZIP    |
| Deploy        | update Lambda        |
| Smoke Test    | validate deployment  |

---

# Recommended GitHub Workflow Structure

# Branch Strategy

| Branch         | Action              |
| -------------- | ------------------- |
| feature/*      | lint + test + build |
| PR to dev/main | validation          |
| dev merge      | deploy dev          |
| main merge     | deploy prod         |

# Why Terraform Deployment Is Better

| Benefit             | Reason                   |
| ------------------- | ------------------------ |
| No infra drift      | Terraform controls infra |
| Versioning          | safer                    |
| Rollback            | easier                   |
| Enterprise standard | yes                      |

---

# Recommended Backend Deployment Pattern

# Feature Branch

Run:

* lint
* tests
* build

NO deploy.

---

# Dev Branch

Deploy:

* dev Lambdas

---

# Main Branch

Deploy:

* prod Lambdas
* manual approval
