# PHASE 5 — React Frontend Application (Complete Detailed Guide)

# Main Goal

Build a production-grade frontend for your serverless e-commerce platform.

Frontend responsibilities:

* Authentication
* Product browsing
* Cart management
* Checkout
* Order history
* Admin management
* API communication
* JWT handling

Your frontend will communicate with:

* Amazon API Gateway
* Amazon Cognito
* Amazon S3

Run:



# Step 4 — Authentication Flow

# Architecture

```text id="tvl09r"
Frontend
    ↓
Cognito Login
    ↓
JWT Token
    ↓
Store Token
    ↓
Attach Token to API Calls
    ↓
API Gateway JWT Validation
```

---

# What You Must Build

# 1. Login Flow

* Call Cognito
* Get JWT token
* Save token
* Redirect user

# 2. Protected Routes

# Step 7 — Image Upload Architecture

# Upload Flow

```text id="fud98n"
Frontend
    ↓
Request Presigned URL
    ↓
Backend Generates URL
    ↓
Frontend Uploads Directly to S3
```

This avoids:

* Lambda size limits
* API Gateway upload issues

Enterprise best practice.
